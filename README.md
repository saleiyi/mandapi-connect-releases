# MandAPI Connect

> Claude Code e Codex, prontos para usar.

MandAPI Connect reúne Claude Code, Codex e seu ambiente local de desenvolvimento em uma única experiência conectada à sua conta MandAPI.

## Recursos

- Claude Code e Codex prontos para usar
- Conta MandAPI: acesse as informações da sua conta e consulte seu saldo
- Acesse sua credencial de API quando precisar
- Terminal integrado
- Seus projetos locais

## Download

Baixe a versão mais recente para Windows:

**[Baixar MandAPI Connect (Windows)](https://github.com/saleiyi/mandapi-connect-releases/releases/latest/download/MandAPI-Connect-Setup.exe)**

Requisitos: Windows 10/11 · x64

Consulte todas as versões publicadas na página de [Releases](https://github.com/saleiyi/mandapi-connect-releases/releases).

## Verificação de integridade

Cada release inclui um arquivo `SHA256SUMS.txt` com o hash SHA-256 do instalador. Para verificar o download no Windows (PowerShell):

```powershell
Get-FileHash .\MandAPI-Connect-Setup.exe -Algorithm SHA256
```

Compare o resultado com o valor publicado em `SHA256SUMS.txt`.
